# Ta Dang Thao - Game QA Portfolio

Static portfolio website for a professional Game QA Tester, ready to deploy on Vercel.

## Run locally

Open `index.html` directly in a browser, or run:

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Use the default static deployment settings.

No build command is required because the site is plain HTML/CSS/JS.
